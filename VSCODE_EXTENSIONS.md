# 🚀 VS Code Extension Önerileri - Bungalow Projesi

## 📦 Zorunlu (Must-Have) Extensions

### 1. **Python** - Microsoft
```
microsoft.python
```
**Neden:** Python geliştirmesi için temel extension
**Özellikleri:**
- IntelliSense (akıllı tamamlama)
- Linting (kod kontrolü)
- Debugging
- Test discovery

---

### 2. **Pylance** - Microsoft
```
ms-python.vscode-pylance
```
**Neden:** Enhanced Python language server
**Özellikleri:**
- Hızlı IntelliSense
- Type checking
- Docstring preview
- Type hint desteği

---

### 3. **Flask** - Don Jayamanne
```
donjayamanne.githistory
```
**Alternatif: Thunder Client**
```
rangav.vscode-thunder-client
```
**Neden:** API testing için (Postman'e benzer)
**Özellikleri:**
- REST API testing
- Request/Response inspection
- Collections

---

## ⚡ Kurulum Komutu

Tüm önerilenleri bir sefer kurmak için terminal'de:

```bash
# Zorunlu (Must-have)
code --install-extension Microsoft.Python
code --install-extension ms-python.vscode-pylance
code --install-extension rangav.vscode-thunder-client

# Önerilenen
code --install-extension alexcvzz.vscode-sqlite
code --install-extension mhutchie.git-graph
code --install-extension eamodio.gitlens
code --install-extension aaron-bond.better-comments
code --install-extension usernamehw.errorlens

# Tema
code --install-extension dracula-theme.theme-dracula
code --install-extension pkief.material-icon-theme
```
